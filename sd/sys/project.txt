PRINTER HARDWARE SPECIFICATION
================================================================================================

Build volume : 415 x 415 x 440 mm
Gantry : HD12 SPAWD AWD
Belts : 12mm 2GT Gates EPDM
Pulleys : 20T GT2
X beam : 2020 aluminium extrusion
  DECISION (04/07/2026): CF tube ruled out — rotor inertia of
  M23CL-76-2804 AWD motors dominates system dynamics, so CF's mass
  advantage over aluminium is no longer significant. Dual MGN9 rail
  sandwich also ruled out — added rail mass increases rotational inertia
  against target ~35k mm/s^2 accel envelope, carries co-planarity risk.
  Revisit only if test prints show diagonal twist artifacts traceable to
  beam torsion.
X/Y rails : MGN12H 550mm (already in hand, x2)
  Toolhead carriage rail: MGN9, sourced AliExpress this session
Z axis : ZR V2.6, SFU1204 ball screws, WobbleX WS12 isolators
Z motors : 42HSB47A41505 brake steppers (79mm, 60 Ncm, 24V brake, 1.5A) —
  power to release. ORIGINAL SET FAILED (see Z BRAKE INCIDENT below).
  Replacement set of 3 ordered this session.
XY/AWD motors: M23CL-76-2804 (18.9 kg/cm, 0.48 kg/cm² rotor inertia) on
  CAN-FD, assisted open-loop (D3). M8 connectors confirmed MALE on motor
  housing (3-pin power, 4-pin CAN) — cables ordered are FEMALE to mate,
  all wired star topology back to TDB (not daisy-chained).
Motion controller: Duet 3 6HC v1.02c SBC mode, RRF 3.6.3
Toolhead : Mellow CNC Vz-HextrudORT water-cooled, Goliath hotend
  (water-cooled variant). Goliath swivel fittings confirmed PLASTIC
  (no metal, no wetted-metal action needed).
  Z PROBE (RESOLVED 04/07/2026): Mellow ALPS Pressure Sensor Module
  (SKU 5030721022) bolts directly onto the water-cooled Goliath coldside.
Extruder : NEMA14, Vz-Hextrudort-Low/WC Plus (air-cooled extruder body,
  separate from Goliath hotend cooling) + Moons 10T motor/gear set
Endstops : Omron EE-SX67x optical (physical, not sensorless) — ordered

SBC : Raspberry Pi 4

CHAMBER HEATING SYSTEM
================================================================================================

Heater : 1400W PTC with shaded-pole motor — bed heater mat CONFIRMED IN HAND
  (400x400mm, 1400W, 220V)
SSR1 : ENMG SDR25A2032 25A — bed heater, gate from Duet OUT7
SSR2 : ENMG SDR25A2032 25A — chamber heater, gate from PLC Q13.2
K1 : Two-pole contactor — mains gate to SSR2, coil driven by R2
K2 : Contactor — shaded-pole fan, coil driven by R3
R1 : Pilot relay — coil from Duet OUT8 (24V), NO contact -> PLC %I0.0
R2 : Pilot relay — coil from PLC Q13.0, contact drives K1 coil
R3 : Pilot relay — coil from PLC Q13.1, contact drives K2 coil
R4 : Pilot relay — coil from PLC Q13.3, contact = spare switched 24V (F6).
  Formerly drove elec bay fans; that function moved to Duet OUT6 / Fan 3.
  Relay and fuse left fitted as a spare PLC-controlled 24V circuit.
PLC : Siemens S7-1200 CPU 1212C DC/DC/Rly, FW V4.3.1, TIA Portal V15.1 Update 8
RTD module : SM1231 8-channel — Slot 2, addresses IW96-IW110.
  Ch0 (IW96) DEACTIVATED — was RTD_ElecBay, function moved to Duet SPI
  daughterboard. Channel deactivated in HW config to suppress broken-wire /
  overflow / underflow diagnostics with the sensor removed.
RS485 module : CB1241 RS485, hardware ID 269, MODE=4 in DB2
HMI : Siemens KTP700 Basic PN, single screen, status indicators only
PROFINET switch: Helmholz 700-850-4PS01 managed switch

PROFINET Network: 192.168.32.0/24, no router
  Pi 4 (DWC)         : 192.168.32.70
  PLC_1 (S7-1212C)   : 192.168.32.71
  KTP700 HMI         : 192.168.32.72
  Helmholz PN Switch : 192.168.32.73 (Port 1=PLC, Port 2=HMI, Port 3=Pi, Port 4=uplink)

AIR-OFF RTD (outstanding):
Labfacility DM-514-D (Farnell part 2081259) — Pt100 thin film, 1.0x3mm,

================================================================================================
SAFETY CIRCUIT — Duet -> PLC (R1)
================================================================================================

Duet OUT8 drives R1 coil directly. HIGH = relay energised = system healthy.
Drops on any Duet stop/estop.

- R1 NO contact -> PLC %I0.0 (DI_EStop_PLC) — 24V when relay energised
- No SR latch in PLC — %I0.0 used directly in FC4. Duet OUT8 is the only latch.
- Duet OUT8 asserted HIGH in config.g at startup.
- Drops via M42 P0 S0 in sleep.g, trigger0.g, trigger3.g.
- OUT8 does NOT drop on M0 (end of print) — only on genuine stop/estop.

================================================================================================
MODBUS RTU — Duet <-> PLC
================================================================================================

Physical layer : Duet 3 6HC onboard RS485 transceiver. RS485_EN jumper fitted.
  IO1 dedicated — do not use IO1 for anything else.
Cable : OSP1 1x2x24AWG overall screened, drain grounded at PLC end only,
  260mm run — no termination resistor needed
Duet config : M575 P2 B9600 S7
Protocol : 9600 8N1, Duet = master, PLC CB1241 = slave address 1
Polling : daemon.g reads all 5 registers every 5s via M261.1 F3 R0 B5
  Read implemented via sub-macro sys/plc_read.g (var scope workaround
  for RRF 3.6.x M261.1 — V parameter creates new var only, never
  overwrites. Sub-macro scope destroys var on return.)
Note : RRF 3.6.x has NO bitwise operators — use mod arithmetic for bit extraction
WARNING : RRF 3.7.0 changes M575 port numbering — P2 becomes P3 for first
  serial port. Do not upgrade to 3.7.x without updating M575 in config.g.

Register Map (DB1, HR40001 base):
  R0  Chamber_SP         Duet->PLC  Int, tenths degC
  R1  Duet_Heartbeat     Duet->PLC  Int, 0-32767
  R2  Duet_Control_Bits  Duet->PLC  UNUSED (was Bit0 = Printer_Active; elec bay
      cooling moved to Duet, bit no longer written or read. DB member retained —
      removing it would shift R3/R4 and break the Modbus map.)
  R3  Chamber_PV         PLC->Duet  Int, tenths degC
  R4  Status_Bits        PLC->Duet  See below

Status_Bits (R4):
  Bit 0 Chamber sensor fault
  Bit 1 Top sensor fault
  Bit 2 Bottom sensor fault
  Bit 3 Heater fault
  Bit 4 PLC heartbeat toggle
  Bit 5 PLC running
  Bit 6 Duet comms OK
  Bit 7 Duet comms fault

================================================================================================
PLC PROGRAM STRUCTURE
================================================================================================

OB1:
  N1 MB_COMM_LOAD (REQ=FirstScan, PORT=269, BAUD=9600, PARITY=0)
  N2 MB_SLAVE (addr=1, MB_HOLD_REG=P#DB1.DBX0.0 BYTE 10)
  N3 FC1 Chamber_Temp_Calc — weighted RTD avg (50/25/25%), fault exclusion
  N4 FB1 FB_Chamber_Comms — Status_Bits assembly, Duet watchdog (10000 scan threshold)
  N5 FC3 AirOff_Sensor — sensor validation, RTD_AirOff -> %MD36
  N6 FC4 FC_Safety — %I0.0 direct, Heater_Enable, PID_Clamp, Heater_Fan
  N7 Chamber heater fault — live assignment, no latch
  N8 REAL_TO_INT Temp_Chamber_PV x 10 -> Modbus_Registers.Chamber_PV

OB30 (cyclic interrupt):
  N1 FC6 FC_SP_Convert — Modbus tenths -> Real degC, clamped 0-120C
  N2 PID_Compact_1 (DB5) — outer loop
  N3 FB2 FB_AirOff_Scale — outer PID -> inner SP, safety cut
  N4 PID_Compact_2 (DB6) — inner loop
  N5 FC5 FC_Heater_Output — PID output -> Int 0-100
  N6 FC7 FC_Heater_PWM — time-proportioning SSR, 2s cycle -> Chamber_Heat_SSR

FC2 Electronics_Cooling — DELETED 31/07/2026. Elec bay cooling moved entirely
  to Duet (Fan 3 on OUT6, ElecBay RTD on S4). FC numbering not reshuffled;
  gap at FC2 is intentional.

SM1222 Output Map (Slot 3, DQ 8x24VDC, base %QB13):
  Q13.0 Chamber_Heat_En  R2 coil -> K1 contactor
  Q13.1 Chamber_Heat_Fan R3 coil -> K2 contactor
  Q13.2 Chamber_Heat_SSR SSR2 gate (chamber heater)
  Q13.3 R4_Spare         R4 coil -> spare switched 24V circuit (F6)
  Q13.4-7 Spare

Key PLC Tags:
  Temp_Chamber_PV            %MD30  Weighted chamber average (Real, degC)
  Temp_Sensor_Fault          %MW44  Sensor fault word
  Temp_AirOff_PV             %MD36  Air-off temperature (Real, degC)
  Chamber_SP_Real            %MD50  Chamber setpoint (Real, degC)
  Outer_PID_Output           %MD54
  Inner_SP_Real              %MD58
  Inner_PID_Output           %MD62
  Heater_Output              %MW42  0-100 Int
  Heater_Cycle_Count         %MW46  FC7 PWM cycle counter
  PID_Clamp                  %M22.3
  Duet_Comms_OK              %M22.4
  AirOff_SafetyCut           %M22.5
  AirOff_Valid               %M22.0
  Chamber_HeaterFault        %M20.1  Live (no latch)
  Chamber_Active             %M20.3
  Chamber_Estop              %M20.0  NOT %I0.0
  Chamber_Heater_Fault_Trig  %M20.4  Live fault trigger
  DI_EStop_PLC               %I0.0   Duet OUT8 -> R1 NO contact -> PLC input

Tags deleted 31/07/2026: RTD_ElecBay (%IW96), Bay_Fans (%Q13.3),
  Cooling_PrinterOn (%M21.1), Fan_Cycle_Count (%MW48).
  HMI bay fan status indicator (bound to Bay_Fans) removed from KTP700 screen

  SUPERSEDES John Guest PM010821E (4mm) / PM011421E (10mm) acetal —

  (static rad-to-reservoir). SUPERSEDES silicone tubing — silicone does
  not retain reliably in push-fit collet fittings (too soft, collet
  teeth don't bite); PU is semi-rigid and is the correct tubing family
  for push-fit systems.

  in wetted path (stainless is the confirmed exception, not silent

  and corrosion-inhibitor package — do NOT add separate biocide.
  ~1L sufficient for this loop; ORDERED this session.

Pump control : PWM via Duet OUT5 (moved from OUT6 31/07/2026), gated by

MACHINE AT A GLANCE  
=======================================================================================================  
415 x 415 x 440mm CoreXY AWD HevORT. Duet 3 6HC v1.02c, SBC mode, Pi 4  
(hostname hevort, user trev). RRF upgraded to 3.7.0-beta.3 on 20/08/2026.  

Motion   : 4x M23CL-76-2804 CAN-FD on 48V via TDB v1.0.  
           CAN 70 = X1 back-right, 71 = X2 front-left,  
           CAN 72 = Y1 front-right, 73 = Y2 back-left.  
           12mm 2GT Gates EPDM belts, Mellow CNC EvoHevORT towers.  
           X beam 20x20x3mm aluminium, single MGN9 rail.  
Z        : 3x 42HSB47A41505 brake steppers, drivers 0.0/0.1/0.2, brakes OUT1.  
           Z0=front-left arm, Z1=rear arm, Z2=front-right arm (M671 order).  
Toolhead : Goliath water-cooled + VZ-HextrudORT Low Plus (12mm bore).  
           Mellow ALPS strain-gauge Z probe on IO6. WS7040 CPAP part cooling.  
Bed      : 440x440x20mm granite + 4mm FR4, 400x400mm 1400W polyimide mat.  
Chamber  : 1400W PTC, Siemens S7-1212C PLC (FW V4.3.1), cascade PID,  
           Modbus RTU to Duet on IO1 (M575 P3 B9600 S7).  
Network  : PROFINET 192.168.32.x — Pi .70, PLC .71, KTP700 .72, switch .73.

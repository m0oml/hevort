Uninsulated faces: Front doors, top lid (polycarbonate — clear)

Sealing

 Front doors : 10×3 mm silicone foam tape on door frame face
 Top lid : 10×3 mm silicone foam tape on lid perimeter
 Panel joints : 10×3 mm silicone foam tape between panels
 Note : All seals silicone-based — handles 60°C+ chamber temp

Thermal estimate (60°C chamber, 20°C ambient, ΔT = 40°C):
 Insulated area ~0.93 m² — loss ~29 W
 Clear PC area ~0.48 m² — loss ~103 W
 Total estimated chamber heat loss ~132 W
 Note: polycarbonate faces dominate (78% of loss, 34% of area)

================================================================================
SAFETY CIRCUIT — Duet -> PLC (R1)
================================================================================

Duet OUT8 drives R1 coil directly. HIGH = relay energised = system healthy.
Drops on any Duet stop/estop.

- R1 NO contact -> PLC %I0.0 (DI_EStop_PLC) — 24V when relay energised
- No SR latch in PLC — %I0.0 used directly in FC4. Duet OUT8 is the only latch.
- Duet OUT8 asserted HIGH in config.g at startup.
- Drops via M42 P0 S0 in sleep.g, trigger0.g, trigger3.g.
- OUT8 does NOT drop on M0 (end of print) — only on genuine stop/estop.

================================================================================
MODBUS RTU — Duet <-> PLC
================================================================================

Physical layer : Duet 3 6HC onboard RS485 transceiver. RS485_EN jumper fitted.
 IO1 dedicated — do not use IO1 for anything else.
Cable : OSP1 1x2x24AWG overall screened, drain grounded at PLC end only,
 260mm run — no termination resistor needed
Duet config : M575 P2 B9600 S7
Protocol : 9600 8N1, Duet = master, PLC CB1241 = slave address 1
Polling : daemon.g reads all 5 registers every 5s via M261.1 F3 R0 B5
 Read implemented via sub-macro sys/plc_read.g (var scope workaround
 for RRF 3.6.x M261.1 — V parameter creates new var only, never
 overwrites. Sub-macro scope destroys var on return.)
Note : RRF 3.6.x has NO bitwise operators — use mod arithmetic for bit
 extraction
WARNING : RRF 3.7.0 changes M575 port numbering — P2 becomes P3 for first
 serial port. Do not upgrade to 3.7.x without updating M575 in
 config.g.

Register Map (DB1, HR40001 base):
 R0 Chamber_SP Duet->PLC Int, tenths degC
 R1 Duet_Heartbeat Duet->PLC Int, 0-32767
 R2 Duet_Control_Bits Duet->PLC Bit0 = Printer_Active
 R3 Chamber_PV PLC->Duet Int, tenths degC
 R4 Status_Bits PLC->Duet See below

Status_Bits (R4):
 Bit 0 Chamber sensor fault
 Bit 1 Top sensor fault
 Bit 2 Bottom sensor fault
 Bit 3 Heater fault
 Bit 4 PLC heartbeat toggle
 Bit 5 PLC running
 Bit 6 Duet comms OK
 Bit 7 Duet comms fault

================================================================================
PLC PROGRAM STRUCTURE
================================================================================

OB1:
 N1 MB_COMM_LOAD (REQ=FirstScan, PORT=269, BAUD=9600, PARITY=0)
 N2 MB_SLAVE (addr=1, MB_HOLD_REG=P#DB1.DBX0.0 BYTE 10)
 N3 FC1 Chamber_Temp_Calc — weighted RTD avg (50/25/25%), fault exclusion
 N4 FB1 FB_Chamber_Comms — Status_Bits assembly, Duet watchdog (10000 scan threshold)
 N5 FC2 Electronics_Cooling — elec bay fan on/off, 30/35C hysteresis + printer active
 N6 FC3 AirOff_Sensor — sensor validation, RTD_AirOff -> %MD36
 N7 FC4 FC_Safety — %I0.0 direct, Heater_Enable, PID_Clamp, Fans_MinSpeed, Heater_Fan
 N8 Chamber heater fault — live assignment, no latch
 N9 REAL_TO_INT Temp_Chamber_PV x 10 -> Modbus_Registers.Chamber_PV

OB30 (cyclic interrupt):
 N1 FC6 FC_SP_Convert — Modbus tenths -> Real degC, clamped 0-120C
 N2 PID_Compact_1 (DB5) — outer loop
 N3 FB2 FB_AirOff_Scale — outer PID -> inner SP, safety cut
 N4 PID_Compact_2 (DB6) — inner loop
 N5 FC5 FC_Heater_Output — PID output -> Int 0-100
 N6 FC7 FC_Heater_PWM — time-proportioning SSR, 2s cycle -> Chamber_Heat_SSR

SM1222 Output Map (Slot 3, DQ 8x24VDC, base %QB13):
 Q13.0 Chamber_Heat_En R2 coil -> K1 contactor
 Q13.1 Chamber_Heat_Fan R3 coil -> K2 contactor
 Q13.2 Chamber_Heat_SSR SSR2 gate (chamber heater)
 Q13.3 Bay_Fans R4 coil -> elec bay fans
 Q13.4-7 Spare

Key PLC Tags:
 Temp_Chamber_PV %MD30 Weighted chamber average (Real, degC)
 Temp_Sensor_Fault %MW44 Sensor fault word
 Temp_AirOff_PV %MD36 Air-off temperature (Real, degC)
 Chamber_SP_Real %MD50 Chamber setpoint (Real, degC)
 Outer_PID_Output %MD54
 Inner_SP_Real %MD58
 Inner_PID_Output %MD62
 Heater_Output %MW42 0-100 Int
 Heater_Cycle_Count %MW46 FC7 PWM cycle counter
 PID_Clamp %M22.3
 Duet_Comms_OK %M22.4
 AirOff_SafetyCut %M22.5
 AirOff_Valid %M22.0
 Chamber_HeaterFault %M20.1 Live (no latch)
 Chamber_Active %M20.3
 Chamber_Estop %M20.0 NOT %I0.0
 Chamber_Heater_Fault_Trig %M20.4 Live fault trigger
 Cooling_PrinterOn %M21.1 Fans minimum speed flag
 DI_EStop_PLC %I0.0 Duet OUT8 -> R1 NO contact -> PLC input
